01 · Change detection

From a form notifier to a production pipeline

Problem / context
Teams downloaded tax forms and compared revisions by hand. The same change could be reviewed several times before reaching a developer.
Architecture / solution
I built the original notifier, then co-built the production platform with engineering colleagues: versioned documents, revision comparisons, change summaries, and links to the development work.

02 · Developer tooling

Give AI the code context and the checks

Problem / context
AI assistants invented syntax for proprietary tax languages and missed dependencies spread across repositories.
Architecture / solution
I built code intelligence with 37 Model Context Protocol tools across 63 repositories, plus build and regression servers. Shared language rules give the model a reference; the real tools check its work.

03 · Data quality

One form identity across disconnected systems

Problem / context
Form titles varied across registries and work trackers. Fuzzy matching missed existing support and created duplicate work.
Architecture / solution
I drove adoption of a persistent form key and built reconciliation scripts with a reviewable decision report. Approved decisions were applied and checked against the source systems.
